# 数字产品中的身份表征与用户体验

## Research Idea

我目前想关注数字产品中的身份表征问题。

一些数字产品在注册或填写个人信息时，会预设一套身份分类方式，例如国家/地区、证件类型、语言等。但这些分类有时无法准确覆盖所有实际用户，部分用户可能只能选择“其他”，或者完全找不到符合自身情况的选项。

我目前想进一步探索：

数字产品中的身份表征不匹配是否会影响用户体验，以及其中是否可能涉及社会身份威胁、归属感等社会心理过程。
